# android_mame

안드로이드 휴대폰과 태블릿에서 아케이드 게임을 즐기기 위한 무료 에뮬레이터 앱입니다.
MAME Plus!(mamep) 0.144u2를 기반으로 합니다.

> **롬(ROM) 파일은 포함되어 있지 않습니다.** 본인이 소유한 게임의 롬만 사용하세요.

## 주요 기능

- mamep 0.144u2 코어 (아케이드 + 가정용 기기), 한글 게임 이름과 검색
- MAMEPlus(Windows) 데이터 가져오기: 한글 목록, 스냅샷, 게임 정보, 치트 등
- 휴대폰: 가상 패드(D패드 / 조이스틱), TURBO 연사, ×2 대시 버튼, 크기·배치 편집
- 태블릿: 키보드·마우스·게임패드, 키 설정
- 같은 Wi-Fi(또는 휴대폰 핫스팟)에서 QR로 최대 4인 온라인 플레이

## 설치

1. [Releases](../../releases)에서 최신 `android_mame-vX.Y.Z.apk`를 받습니다.
2. 안드로이드에서 "출처를 알 수 없는 앱 설치"를 허용하고 설치합니다.
3. 앱에서 롬 폴더를 선택합니다.

모든 릴리스는 같은 키로 서명되어 있습니다. 받은 APK가 이 프로젝트의 것인지 확인하려면
서명 인증서의 SHA-256 지문을 비교하세요.

```
09:E6:F7:3B:36:24:AB:DC:2F:91:84:98:55:88:CE:D0:43:53:1A:BF:3A:D6:3C:3E:AC:90:AA:A3:97:21:A7:61
```

## 소스와 라이선스

- 각 릴리스에는 그 버전의 전체 소스(`android_mame-X.Y.Z-source.zip`)가 함께 첨부되어 있습니다.
  이 소스에는 사용한 mamep 0.144u2 원본 소스와 적용한 패치가 포함됩니다.
- MAME와 mamep는 **MAME 라이선스**(0.172 이전)를 따릅니다. 이 앱은 무료이며 **판매하거나
  상업적으로 사용할 수 없습니다.** 재배포할 때는 소스를 함께 제공해야 합니다.
- 전체 라이선스 문구와 사용한 오픈소스 라이브러리 목록은 앱의 설정 > "라이선스 및 소스"에서
  볼 수 있습니다.
